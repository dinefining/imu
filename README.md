# imu

Two people on the same black page. Each person sees only their own cursor. Find each other for a big hug.

## How to play

- Click **invite**, copy the link, send it to someone, then click **enter**.
- The six squares at the top tell you how close you are, but never which way. They go from cold blue when you're far apart to warm orange when you're close.
- Get close and you'll see each other. Stay together for a second and you've found each other.
- The five squares in the bottom-left set the difficulty, from green (easy) to red (hard).
- The speaker in the bottom-right turns on sound.

A [Maybe Machine](https://maybemachines.com) by [Ravi Popat](https://ravipopat.info).
